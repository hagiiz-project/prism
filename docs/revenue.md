# プリズム 収益設計

## 全体の考え方

収入を「大きいが不安定なもの」と「小さいが途切れないもの」に分け、**後者で生業を成り立たせ、前者で伸ばす**。年間契約とマッチングは金額が大きいが、契約更改と社会情勢に左右される。素材のアフィリエイトは1件が小さいかわりに、授業と催しが行われるかぎり止まらない。

| # | 収益源 | 1件の大きさ | 安定性 | 立ち上げ | 優先 |
|---|---|---|---|---|---|
| 1 | 素材アフィリエイト | 小 | **高** | すぐ | **第1期** |
| 2 | 送客手数料（購入・予約） | 小〜中 | 中 | すぐ | 第1期 |
| 3 | 依頼マッチング手数料 | **大** | 低〜中 | 半年 | 第2期 |
| 4 | 提供者ダッシュボード月額 | 中 | **高** | 実践記録が要る | 第2期 |
| 5 | 自治体・教育委員会 年間契約 | **大** | 低（単年度） | 1年 | 第3期 |

**全期間を通じた禁止事項：掲載順位を売らない。** 上位表示を金で買える瞬間に、実施記録の信用が消える。信用が消えると1〜5のすべてが同時に死ぬ。広告主に売るのは順位ではなく、分析と接点である。

---

## 1. 素材アフィリエイト（土台）

### なぜこのサイトに向くか

広告を差し込む必要がない。**準備物リストが最初から買い物リストだから。** 進行プランを作れば「霧吹き4本・砂3kg・模造紙」が出る。これは押し売りではなく、利用者が来た目的そのもの。

### 数字

146件を分解した結果：**物品879点。うち毎回買い直す消耗品が585点（67%）。**

消耗品比率が高いことが、この収益源の性質を決めている。耐久品（顕微鏡・双眼鏡）は一度売れたら終わりだが、砂・模造紙・付箋・乾電池・ペットボトルは**実施のたびに減る**。授業が行われるかぎり需要が再生する。

### 単位経済（料率は各プログラムの規定に従って要調整）

```
1回の実施あたりの消耗品購入      2,000〜5,000円
料率                            数%（Amazon/楽天とも品目により変動）
1実施あたりの収益               おおむね数十〜百数十円
```

小さい。だから**実施回数そのものを増やす設計**が収益設計と一致する。ここが重要で、利用者のためになること（進行プランを配り、実施を増やす）と、収益が増えることが同じ方向を向く。広告モデルではこうならない。

### 開示について（方針変更を進言した箇所）

**隠さない。** 理由は倫理ではなく運用である。

- Amazonアソシエイト・楽天アフィリエイトは、参加者である旨の表示を規約で義務づけている。違反はアカウント停止に直結する
- 日本では2023年10月からステルスマーケティング規制が施行されている
- 隠して得られる上乗せ分より、口座停止で失う全額のほうが大きい

かわりに**「退屈にする」**。1商品ごとに注記を付けず、準備物ブロックの下に小さく1行だけ置く。リストが本当に役立つとき、開示は転換率をほとんど下げない。

```
この一覧のリンクから購入があった場合、プリズムに手数料が入ります。
掲載順や表示内容は手数料の有無で変えていません。
```

後半の1文が重要。**開示は免罪符ではなく、約束の宣言として書く。**

### 安全に関わる物品は購入導線を出さない

保護めがね、ヘルメット、解剖ばさみ、火気を使うもの。規格を満たさない安価品が上位に出る危険があるため、**人が確認するまで購入先を表示しない**（実装済み。146件中40点が該当）。ここで数十円を取りにいくと、事故が起きたとき事業ごと終わる。

### 実施記録が精度を上げる

この仕組みの独自性は、**買ったあとの情報が返ってくる**ことにある。

- 「霧吹き4本では35人に足りず、8本にした」
- 「砂は園芸用で代用できた」
- 「養生シートは新聞紙とゴミ袋で足りた」

代用できた、という記録は短期的には売上を減らす。それでも載せる。**代用案まで正直に書いてあるリストだから次も使われる**のであって、買わせるだけのリストは二度目に開かれない。

## 2. 送客手数料（購入・予約）

対象は購入34件・予約32件。掲載物そのものへの送客。

- 成果報酬。提供者は掲載自体は無料
- **予約は日付があるため、締切効果で転換率が高い**
- 料率は提供者と個別。公的機関・学校法人からは取らない（取ると公的機関が載らなくなり、カタログの網羅性が壊れる）

第1期はASP経由の一般的なアフィリエイトで始め、実績が出てから直接契約に移す。

---

## 3. 依頼マッチング手数料（金額が最も大きい）

対象は**要見積もり29件**。さかなクン、今村文彦、大隅典子、出張授業、講演。1件5万〜30万円が動く。

### いま何が壊れているか

- 依頼する側：誰にいくらでどう頼めばいいかわからない
- 依頼される側：予算の書かれていない問い合わせで時間が溶ける

### プリズムだけが持てる材料

**実施記録である。** 「45分・35人・小学校高学年で、時間内に収まった」という記録は、講師紹介会社が構造的に持てない。ここが手数料の根拠になる。

### 設計

- 問い合わせフォームで**予算の上限を必須にする**。書かせない問い合わせは双方の損失
- 候補日を2〜3提示させる
- 成約時に10〜15%。不成立なら無料
- **断りやすくする。** 断られた記録も残し、「この条件では断られやすい」を次の依頼者に返す。断りにくい仕組みは、呼ばれる側を消耗させて供給が枯れる

## 4. 提供者向けダッシュボード（月額）

売るのは順位ではなく**分析**。

| 無料 | 有料（月額 3,000〜10,000円想定） |
|---|---|
| 掲載、閲覧数、リアクション数 | 場面別の実施件数と条件の分布 |
| | 元の進行案からの**変更の内訳**（どこが削られたか） |
| | 反応が最も大きかった工程の分布 |
| | 再利用の見通し（条件が合えば／改善すれば／使わない）の推移 |
| | 同種の掲載物との比較（匿名・集計値のみ） |

「どこが削られたか」は教材改良に直結し、他のどこでも買えない。**個人コミュニケーターが払える価格に置く**こと。企業しか払えない価格にすると、掲載の多様性が失われて、カタログとしての価値が下がる。

---

## 5. 自治体・教育委員会 年間契約

学校単位ではなく**地域単位**。価値は掲載物ではなく、**地域内で実施記録が共有されること**にある。同じ市の別の学校が「45分・35人でできた」と書いてあれば、次の学校の準備時間が消える。

- 単年度契約であり、担当者の異動で消える。**大きいが不安定な収入として扱う**
- 実績（域内の実施記録件数、削減された準備時間）を毎年出せる状態にしておく
- ここに依存した固定費構造を作らない

## 立ち上げ順序

**第1期（〜6か月）**　準備物リストの精度を上げる。アフィリエイトと送客手数料を回す。実施記録を集める。ここでは黒字化を目指さない。目的は記録の蓄積。

**第2期（6〜18か月）**　実施記録が材料になったところで、依頼マッチングと提供者ダッシュボードを開く。**この2つは実施記録がないと成立しない**ので、順序を逆にできない。

**第3期（18か月〜）**　地域単位の年間契約。第1・2期の実績が営業材料になる。

---

## 守るべき一線

1. 掲載順位を売らない
2. 手数料の有無で表示を変えない、と書いたら本当に変えない
3. 安全に関わる物品は、確認がすむまで購入導線を出さない
4. 代用できるものは「代用できる」と書く
5. 提供者の推奨条件を、実施記録で書き換えない

5つとも短期的には収益を減らす。それでも守る理由は単純で、**この5つがプリズムの唯一の参入障壁だから**である。品揃えは真似できる。デザインも真似できる。「金を払っても順位が変わらない場所」という評判だけは、真似ができない。
